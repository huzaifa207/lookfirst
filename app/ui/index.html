LookFirst

Private repository?

For an ssh address, LookFirst uses your own ssh keys. For an https address, paste an access token with read-only access. It is sent only to github.com, gitlab.com or bitbucket.org, used for this check, and never saved.

Reads the repository without cloning it and never runs Git. This is the one check that goes online.

Before you open a project, a code test, or a pack of documents someone sent you, LookFirst checks it for files that run code by themselves: when you open the folder, switch a Git branch, or install it.
